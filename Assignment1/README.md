# Assignment 1: Converter and Pixel System

## Description

This assignment demonstrates how information can be represented using bits, bytes, number bases, characters, and pixels.

## Programs

### ASCII-to-Decimal Converter

Converts characters into their ASCII decimal values.

### Number Base Converter

Converts numbers between:

- Binary
- Decimal
- Octal
- Hexadecimal

### Image-to-Pixel Converter

Reads an image and prints the RGB values of its pixels.

### Pixel-to-Image Converter

Reads pixel values and uses them to create an image.

## Testing

The programs were tested using normal and boundary cases:

- My name (Fredric)
- Zero (`00000000`)
- The largest 8-bit unsigned value
- A negative 8-bit two's-complement value (-5)
- An image of a smiley face

## How to Run

1. Download or clone this repository.
2. Open the project in a Java-supported IDE.
3. Compile the program you want to use.
4. Run the program and follow the instructions displayed in the terminal.
